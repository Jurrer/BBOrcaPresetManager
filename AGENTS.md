## Project design

The full design spec lives in `plan.md`. Domain terms live in `GLOSSARY.md`. Read both before working on this project.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (repo `Jurrer/BBOrcaPresetManager`), operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical triage labels are used: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `GLOSSARY.md` at the repo root and `docs/adr/` for architecture decision records. See `docs/agents/domain.md`.
